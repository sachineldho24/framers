Step 1 — Entry
Ways to frame a digital photo
framebridge.com/pages/digital-uploads
Layout
Full-width dark nav. 3 option rows with thumbnail + title + price. Clean scannable hierarchy.
Entry paths
Design Custom Frame · Father's Day Gifts · Gallery Walls — each priced with starting point.
Good UX
Prices shown upfront ($70+, $40+, $175+). Reduces surprise friction later in checkout.
Friction
No personalisation cue — user doesn't know what to expect once they pick a path. No preview.
3-option list thumbnail thumbnails anchored price promise badge secondary "shop all" link
8/10Clear
Decisive entry point. Price anchoring at entry is a strong trust signal. Could benefit from a "how it works" micro-explainer.
Step 2 — Upload
Great! Let's add your photo.
digital > photo > size
Split layout
Left panel: copy + action. Right panel: full-height dashed drop-zone with placeholder icon. 50/50 split, very spacious.
Primary CTA
Yellow "Upload Photo" button — high contrast, unambiguous. QR-based phone upload as secondary option.
Smart design
Warm copy ("We can't wait to see it!") reduces anxiety about uploading personal photos online.
Gap
No file format hints visible (JPG/PNG/TIFF?), no size limit warning, no social import option.
Breadcrumb nav
"digital > photo > size >" at top-left shows progress context. Users know they're at step 1 of 3. Exit button always visible top-right — reduces commitment anxiety.
breadcrumb progress exit link yellow CTA drag & drop zone QR phone upload placeholder icon
7/10Good
The split-screen layout makes the drop zone feel premium. QR code for phone is clever. Missing: format/size guidance, social import (Google Photos, iCloud).
Step 3 — Size
Find the right size.
digital > photo > size >
Layout
Left: size controls. Right: live mat preview with photo inside dashed mat border — updates in real time.
Live preview
Actual uploaded photo shown at scale inside the mat/frame preview — eliminates guesswork. Critical trust feature.
Size picker
Horizontal slider: XS ($70+) · S ($90+) · M ($125+). Specific size shortcuts: 5x7", 8x10", 11x14".
Transparency
"Your photo can be printed up to 10″ × 17.75″" — resolution limit communicated clearly to prevent disappointment.
Gaps
Only 3 tiers shown on slider — no drag to custom dimension. DPI/quality indicator absent. Mat colour not selectable here.
Bottom actions
"Edit Your Photo" + "View in Room" at panel bottom — progressive disclosure, not cluttering the main flow.
horizontal slider price tiers dimension display standard size shortcuts live photo preview mat border preview edit / room view yellow CTA: Next: Pick A Frame
9/10Excellent
Best step in the flow. Live preview with the actual photo is a standout feature. Slider + quick-picks dual pattern is smart. Print limit disclosure is honest and prevents churn. Minor: no resolution quality indicator or mat colour teaser.
Step 4 — Frame select
Frames for Digital Photos
framebridge.com/apps/designer/framing-flow/frame-select
Layout
Dense 3-column thumbnail grid. Every frame shown with the user's actual photo — not a stock image. 60+ frames visible.
Personalised grid
Each thumbnail renders the user's own photo in that frame. Eliminates mental work of imagining how it'd look.
Frame metadata
Name, short description (material + style), and price under each thumbnail. Consistent info hierarchy.
Friction
No filter by colour, material, or price. 60+ options with no sort/filter = decision fatigue. No "recommended for this photo" signal.
Navigation
No sticky breadcrumb visible — user loses sense of position in flow. Back navigation unclear from the fetched page.
Selection CTA
Orange highlight ring on selected frame (visible in screenshot). Yellow CTA likely progresses to mat/checkout.
3-col thumbnail grid user photo in each frame frame name + desc price per frame selection highlight sort control (top)
7/10Good
The personalised grid is the killer feature — seeing your own photo in every frame is highly effective. Hurt by the absence of colour/material/price filters. Decision fatigue is real at 60+ options. A "curated picks for your photo" row at the top would help.
